# Публичный префикс назначается экземпляру сервис-провайдера

Один экземпляр может обслуживать несколько протоколов, а один тип сервис-провайдера может иметь несколько экземпляров. У каждого экземпляра свой публичный префикс, под которым шлюз выделяет отдельный корень каждому протоколу и проверяет права каждой публикации. При явном переходе на вложенные адреса план показывает старые и новые URL, а применение закрывает прежние маршруты переведённых публикаций с сохранением их ID и прав.
