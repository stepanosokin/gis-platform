# Общий черновик конфигурации

Операции с подключениями к PostGIS, экземплярами сервис-провайдеров, публикациями и настройками регистрации готовят один черновик рядом с рабочим YAML. Общий черновик позволяет проверить зависимые изменения одним планом и сохраняет базу относительных путей. План учитывает исходную версию, рабочий YAML и редакцию черновика. Рабочий YAML обновляется при успешном применении, а черновик остаётся доступен при сбое.

Режим публикации входит в конфигурацию. Персональные разрешения остаются в базе доступа и меняются для действующего закрытого сервиса через локальный административный API. Так выдача или отзыв разрешения вступает в силу без развёртывания и сохраняет действующие правила отката.
