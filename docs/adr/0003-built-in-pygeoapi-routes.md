# Публичные маршруты встроенного pygeoapi

Встроенный экземпляр pygeoapi получает публичный префикс `/pygeoapi` со страницей экземпляра и отдельными корнями Features, Maps и Tiles. Планирование из того же YAML переводит публикации с прежнего корня `/features` на новые адреса, сохраняя ID и права доступа. Подтверждённая версия хранит свои маршруты для отката. Если `/pygeoapi` уже занят другим экземпляром, оператор разрешает конфликт в YAML перед применением плана.
