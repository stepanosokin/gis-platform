# Публичный адрес развёртывания и порт шлюза

Внешний HTTPS-прокси может принимать запросы на одном порту и подключаться к шлюзу GIS Platform на другом. Необязательное поле `server.public_url` задаёт единый публичный адрес развёртывания. Платформа использует этот адрес в ссылках API, OpenAPI, перенаправлениях, настройках CORS, при входе и в ссылках в письмах. Привязка порта Caddy и его локальные проверки в `config apply` и `doctor` используют `server.port`. Явный публичный адрес позволяет проверить шлюз до подключения прокси и получать одинаковые ссылки при прямых и проксированных запросах.

В первой версии прокси и шлюз используют HTTPS с общим DNS-именем. Публичный адрес содержит схему `https`, имя из `server.host` и необязательный внешний порт. Допустим завершающий `/`. Например, для `https://gis.example.org` прокси может подключаться к шлюзу на порту `1443`. При отсутствии `server.public_url` платформа строит публичный адрес из `server.host`, `server.port` и `server.tls`.

Изменение публичного адреса отражается в плане и применяется через `config apply`. Откат восстанавливает публичный адрес выбранной версии.
