---
name: gis-list-users
description: Показать учётные записи GIS Platform с доступными публикациями и сохранить список пользователей в Excel.
---

Уточни развёртывание, если оно не определено. Для экспорта уточни путь `.xlsx`, если пользователь его не указал. Используй локальный административный API с правом `users-read`, описанный в [ADMIN.md](../../../ADMIN.md#настройка-закрытых-публикаций-и-локального-cli).

- Список: `node dist/cli.js users list --json`. Покажи отображаемое имя, email, дату регистрации и доступные публикации. Учитывай флаг `anonymous` для публичного доступа.
- Excel: `node dist/cli.js users list --xlsx <file.xlsx> --json`. Покажи путь и число строк. Сохрани файл в указанном пользователем месте.

На удалённом сервере команду выполняет пользователь.
