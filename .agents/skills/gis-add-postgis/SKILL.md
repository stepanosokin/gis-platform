---
name: gis-add-postgis
description: Добавить именованное подключение к внешней базе PostGIS в черновик GIS Platform.
---

Уточни целевое развёртывание, путь к рабочему YAML и недостающие обязательные поля: ID подключения, хост, имя базы, имя пользователя БД и путь к файлу пароля на целевом хосте. Порт PostGIS по умолчанию 5432. Содержимое файла пароля остаётся на хосте.

Запиши параметры `host`, `database`, `user`, `password_file` и при необходимости `port` в YAML-файл настроек. Относительные пути отсчитываются от рабочего YAML. Выполни `node dist/cli.js draft postgis <platform.yaml> <id> <settings.yaml> --json`.

Покажи ID подключения и путь к черновику. Соединение с БД проверяется при применении первой публикации, которая его использует. Для применения используй [deploy](../deploy/SKILL.md). На удалённом сервере команду выполняет пользователь.
