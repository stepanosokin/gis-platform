---
name: deploy
description: Подготовить и применить план GIS Platform из общего черновика или готового платформенного YAML.
---

1. Определи рабочий YAML, Docker context, Compose-проект и каталог состояния. Для действующего развёртывания сохрани текущие `GIS_PUBLIC_BIND` и порт HTTP-перенаправления при TLS. Спроси параметры, которые пользователь не указал и которые нельзя установить по [состоянию развёртывания](../../../ADMIN.md#найти-развёртывание-и-проверить-состояние). Для удалённого сервера выдай команды для запуска пользователем.
2. Для черновика выполни `node dist/cli.js config plan --draft <platform.yaml> --json`. Для готового файла, который явно выбрал пользователь, используй `config plan <file> --json`.
3. Покажи ID, базовую версию, добавленные, изменённые и удаляемые компоненты, изменения URL и доступа и список затронутых маршрутов. Попроси подтвердить применение показанного плана.
4. Примени подтверждённый план через `node dist/cli.js config apply <plan-id> --json`. Сверь действующую версию через `status --json` и готовность через `doctor --json` в том же окружении.
5. При конфликте или сбое сообщи код CLI и текущую фазу. После обрыва связи проверь состояние прежде, чем повторять тот же ID. Если изменился черновик, заново покажи план и получи подтверждение.

Подготовка окружения описана в [ADMIN.md](../../../ADMIN.md#подготовка-окружения-и-yaml).
