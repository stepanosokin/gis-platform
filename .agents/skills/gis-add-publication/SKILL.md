---
name: gis-add-publication
description: Добавить в черновик GIS Platform публикацию пространственных данных через выбранный протокол.
---

Уточни целевое развёртывание, рабочий YAML и недостающие поля публикации: постоянный ID, название, описание, источник, экземпляр сервис-провайдера, протокол, охват и режим доступа. Поля по конкретному источнику и протоколу сверяй со [схемой](../../../src/platform.schema.json). Документация о [публикациях](../../../ADMIN.md) помогает выбрать совместимые настройки.

Подготовь YAML с полями публикации из `publications.<id>`. Для нового источника добавь в этот же файл `source_settings` со значением для `sources.<source>`. Если источник PostGIS ссылается на новое подключение, сначала используй [gis-add-postgis](../gis-add-postgis/SKILL.md). Режимы `registered` и `private` требуют `auth` в конфигурации.

Выполни `node dist/cli.js draft publication <platform.yaml> <id> <settings.yaml> --json` и покажи результат. Для применения используй [deploy](../deploy/SKILL.md). На удалённом сервере команду выполняет пользователь.
