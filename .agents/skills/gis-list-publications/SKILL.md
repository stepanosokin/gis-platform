---
name: gis-list-publications
description: Показать список публикаций из действующей версии GIS Platform с каноническими URL и экземплярами сервис-провайдеров.
---

Если развёртывание ещё не определено, уточни Compose-проект и каталог состояния. Выполни `node dist/cli.js publications list --json` в окружении развёртывания.

Покажи название, канонический URL, протокол и экземпляр сервис-провайдера. Используй ID для уточнения одноимённых публикаций. Если версия ещё не подтверждена, сообщи фазу из `status --json`. На удалённом сервере команду выполняет пользователь.
