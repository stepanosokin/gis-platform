---
name: gis-enable-auth
description: Подготовить в черновике GIS Platform включение регистрации, входа, почты и при необходимости локального административного API.
---

Уточни развёртывание, путь к рабочему YAML и какой режим нужен. Для `development` используется Mailpit на порту 8025 по умолчанию. Для `production` уточни хост и порт SMTP-реле, отправителя и режим шифрования, если его нельзя определить по настройкам. Если реле требует аутентификацию, уточни имя пользователя и путь к файлу SMTP-пароля.

Уточни пути к независимым файлам секрета приложения и пароля PostgreSQL учётных записей, а также email администраторов, если нужны. При первом включении помоги подготовить файлы по [инструкции](../../../ADMIN.md#включить-регистрацию-и-почту). Значения секретов должны оставаться в файлах на хосте.

Если пользователь просит посмотреть пользователей или управлять персональными разрешениями, предложи настроить локальный административный API в том же черновике. Для API уточни порт, пути к выданному УЦ и серверной паре и права операторов. Добавь их в `cli` по [инструкции настройки](../../../ADMIN.md#настройка-закрытых-публикаций-и-локального-cli).

Составь отдельный YAML с содержимым блока `auth` и выполни `node dist/cli.js draft auth <platform.yaml> <auth-settings.yaml> --json`. После подтверждённого [deploy](../deploy/SKILL.md) проверь наличие ссылок на регистрацию и вход. На удалённом сервере команду выполняет пользователь.
