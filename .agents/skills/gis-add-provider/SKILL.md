---
name: gis-add-provider
description: Добавить экземпляр сервис-провайдера из Docker-образа в черновик GIS Platform.
---

Уточни целевое развёртывание, рабочий YAML, ID экземпляра, образ с версионным тегом или digest и файл интеграции. Если файла интеграции нет, узнай тип адаптера, нужные протоколы и недостающие поля из [схемы](../../../src/platform.schema.json). Пример для нескольких протоколов есть в [examples/provider-protocols.yaml](../../../examples/provider-protocols.yaml).

Выполни `node dist/cli.js draft provider <platform.yaml> <id> <image> <integration.yaml> --json`. Образ указывается отдельным аргументом. Файл интеграции содержит параметры экземпляра, включая поддерживаемые протоколы и настройки маршрутов.

Покажи ID экземпляра и путь к черновику. Развёртывание и закрепление образа проходят через [deploy](../deploy/SKILL.md). На удалённом сервере команду выполняет пользователь.
